# Workout Tracker AI

A browser-based workout app that can import exercise files, format them into a clean tracker, and provide simple AI-style coaching prompts.

## What you can do
- Upload workout docs/spreadsheets (`.csv`, `.tsv`, `.txt`, `.json`, `.xlsx`, `.xls`).
- Auto-map common workout columns (exercise, sets, reps, weight, notes, etc.).
- Add workouts manually with exercise descriptions/explanations.
- Track sets, reps, weight, duration, and notes.
- Filter workout history by type and review quick stats.
- Ask a built-in simple AI coach for summaries and plan suggestions.
- Use the app on iPhone (mobile responsive + installable web app metadata).

## How to use
1. Open `index.html` in your browser.
2. Use **Import File** to load a document/spreadsheet, or add entries manually.
3. Ask the AI section questions like “Summarize this week”.
4. Your data is saved locally in browser `localStorage`.

## iPhone access
- Host this project on GitHub Pages (or any HTTPS static host).
- Open the app URL in Safari on iPhone.
- Optional: tap **Share → Add to Home Screen** to launch it like an app.
