# Workout Tracker

A simple browser-based workout tracker app.

## Features
- Log workouts by date, type, and exercise name.
- Store optional sets, reps, weight, duration, and notes.
- View calculated summary stats (total workouts, minutes, volume, and unique exercises).
- Filter workout history by workout type.
- Delete single workouts or clear all workouts.
- Data persists in browser `localStorage`.

## Run locally
Open `index.html` in your browser.
